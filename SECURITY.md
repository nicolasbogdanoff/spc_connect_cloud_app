# Política de seguridad

## Versiones soportadas

| Versión | Soporte |
| --- | --- |
| `main` | Sí |
| Releases anteriores | Solo cuando se indique expresamente |

## Reportar una vulnerabilidad

No publiques credenciales, datos de procesos ni una prueba de concepto sensible en un issue público. Usa el canal privado de vulnerabilidades de GitHub si está habilitado para el repositorio. Si no está disponible, abre un issue sin detalles sensibles solicitando un canal privado.

Las observaciones sobre cálculos estadísticos, validación de entradas o exportación de resultados también son bienvenidas como issues normales cuando no contienen información confidencial.
